# Thirukkural

A modern, minimalist, and responsive web application to read and study the timeless 1,330 couplets of the **Thirukkural** by Thiruvalluvar.

## Features

- **All 1,330 Couplets**: Complete collection across the 3 sections (*Aram*, *Porul*, *Inbam*) and 133 chapters.
- **Bilingual & Transliteration**: Full Tamil script, phonetic English transliteration, and English translation.
- **Progress Tracking & Streaks**: Local progress recording, daily reading counts, and streak tracking (saved locally in your browser).
- **Bookmarks**: Save favourite kurals and toggle between full reading mode and bookmarked kurals.
- **Keyboard Navigation**: Arrow keys to navigate couplets, number keys (1, 2, 3) to switch sections, and shortcuts for quick search/jump.
- **PWA (Progressive Web App)**: Installable directly to your device home screen for offline reading.

## Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build for GitHub Pages / Static Hosting

```bash
npm run build:static
```
